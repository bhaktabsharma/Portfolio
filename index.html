Bug Bounty / Pentesting · Bash

Bug Bounty Recon Engine

Automates the first mile of a bug bounty engagement — turns a domain into a structured attack-surface map in one self-contained, checkpointed Bash script that can be safely killed and resumed.

What it covers

  • Subdomain enumeration
  • Live host discovery (HTTP probing)
  • URL collection
  • Parameter discovery
  • JavaScript endpoint extraction
  • API endpoint discovery
  • Candidate generation: takeover candidates, GF patterns and Nuclei findings

Output is a structured map of leads for manual review. It does not prove that any vulnerability exists.

Proof
10-phase pipeline · resumable checkpoints · wraps subfinder, httpx, nmap, katana, ffuf, nuclei
Output
